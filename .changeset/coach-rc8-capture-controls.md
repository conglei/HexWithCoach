Coach RC-8 capture controls. Adds an Incognito "don't save" mode: when on, dictation still inserts text but nothing is retained — no transcript, no audio, nothing for the Coach corpus. Toggle it quickly from the Home header (with a status line when active) or from a new Settings ▸ Privacy section, which also states the capture posture plainly: capture is local by default, the Coach only uploads when you connect a key, and password/secure fields use the system keyboard so they're never captured. (Per-app exclusion isn't possible from a keyboard extension — it can't see the host app — so it's intentionally omitted.)
